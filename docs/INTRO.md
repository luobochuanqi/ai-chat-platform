# AI 探索平台

面向初中生的 AI 体验平台，提供两个 AI 模型供学生上手使用。

## 模型

- **DeepSeek Flash** — AI 对话模型，可以聊天问答
- **Seedream 5.0 Lite** — AI 生图模型，输入文字描述即可生成图片

## 功能

### 学生端

- **AI 对话** — 多轮聊天，支持多个独立会话，随时新建/删除/切换对话
- **AI 生图** — 输入提示词生成图片，每人有固定额度
- **作品墙** — 浏览同学们被管理员精选展示的 AI 画作，可以给喜欢的作品点赞

### 管理员端

- **用户管理** — 批量创建学生账号，启用/禁用/删除用户
- **额度管理** — 每个学生有对话和生图的总额度限制，用完后可联系管理员追加
- **作品审核** — 查看所有学生生成的图片，选择优秀的公开到作品墙
- **数据统计** — 查看平台使用概况（用户数、对话数、作品数）

## 部署方式

Docker 容器化部署，两条命令启动：

```bash
docker-compose up -d
```

访问 `http://localhost` 即可使用。
