# AI 生图 · 课程大纲

> **适用对象**：初中生（零基础），50 人电脑课
> **课时**：2 节 × 50 分钟，分两天
> **平台**：AI 探索平台 — AI 生图（Seedream 豆包）+ 作品墙
> **设计日期**：2026-07-25

---

## 一、课程目标

通过两节课，让学生：

1. 体验 AI 生图的能力与边界
2. 掌握**自然语言提示词**的写法（主体 + 场景 + 风格 + 镜头语言 + 氛围 + 细节），能稳定产出质量不错的图片
3. 第一天结合**红军长征 90 周年**（1936—2026），用 AI 重现历史场景，融合历史认知与德育
4. 第二天接触多种**图片风格**，建立风格词库，打开创作想象

---

## 二、核心方法

### 2.1 提示词的本质：自然描述，不是标签表格

⚠️ **重要**：生图提示词是一段**自然描述**（词组 / 短句，逗号连接），**不是**「主体：xxx 场景：xxx 风格：xxx」这种带标签的表格。模型不需要「主体」「场景」这种元标签，带标签反而可能被模型当成画面内容，干扰出图。

**进阶公式**（参考[阿里云万相官方 Prompt 指南](https://help.aliyun.com/zh/model-studio/text-to-image-prompt)）：

```
主体描述 + 场景描述 + 风格 + 镜头语言 + 氛围词 + 细节修饰
```

- **镜头语言**用专业词：景别（特写 / 中景 / 远景镜头）、视角（平视 / 俯视 / 仰视 / 航拍）、镜头类型（微距 / 广角 / 长焦 / 鱼眼）

官方范例（注意：自然语言，元素都在，但**没有任何标签**）：

> 25岁中国女孩，圆脸，看着镜头，优雅的民族服装，商业摄影，室外，电影级光照，半身特写，精致的淡妆，锐利的边缘

### 2.2 八维分析工具（写 prompt 前的拆解）

真正动笔写 prompt 前，先用 8 个维度把「我想要什么」想清楚。这是**纸上的拆解**，帮学生理清思路——**不是直接喂给模型**。

| 维度 | 回答什么 | 思考示例 |
|---|---|---|
| 主体 | 谁/什么，外貌穿着动作表情 | 一个 15 岁红军小战士，八角帽红五星，瘦削坚定 |
| 场景 | 在哪、什么时间、背景 | 雪山下行军，苍茫雪线 |
| 风格 | 什么画种/参考谁 | 写实历史人像摄影 |
| 光线 | 光的方向/性质/色温 | 侧逆光，暖色夕阳 |
| 构图 | 构图法/镜头/视角/景深 | 半身特写，三分法 |
| 色彩 | 主色调/饱和度 | 暖橙 + 冷蓝 |
| 氛围 | 什么情绪 | 坚定、纯真 |
| 画质 | 清晰度/质感 | 高度细节，真实皮肤质感 |

### 2.3 从拆解到 prompt：翻译（教学的关键一步）

把 8 维拆解的结果，**揉成一段自然描述，去掉所有标签**——这才是实际喂给模型的 prompt。

**对比示例**：

拆解（纸上思考，给学生看结构）：

```
主体：一个 15 岁红军小战士，八角帽红五星，瘦削但坚定
场景：雪山下行军，背景苍茫雪线
风格：写实历史人像摄影
光线：侧逆光，暖色夕阳
构图：半身特写，三分法
色调：暖橙 + 冷蓝
氛围：坚定、纯真
画质：高度细节，真实肤质
```

翻译成 prompt（**喂给模型**，无标签）：

```
半身特写镜头，三分法构图，一个 15 岁的红军小战士，瘦削但眼神坚定，戴八角帽缀红五星，灰布军装满是补丁，脸上有冻伤和尘土，望向远方。雪山下行军途中，背景是苍茫雪线和低垂云层。写实历史人像摄影风格，电影剧照质感。侧逆光，暖色夕阳打在脸上，眼神光清晰。暖橙夕阳光与冷蓝背景对比。坚定、纯真的氛围。高度细节，真实皮肤质感，8K。
```

### 2.4 长度约束

提示词总长不超过 **300 汉字**（平台硬限制，`images.py:_truncate_prompt` 超出会自动截断）。控制在一二百字留余量。

### 2.5 进阶阶梯（L1 → L5）

教学时带学生一层层加内容，每加一层出一个图，看画面变好：

| Level | 加什么 | 效果 |
|---|---|---|
| L1 | 主体 | 平淡，路人感 |
| L2 | +场景 | 有内容，但寡淡 |
| L3 | +风格 | 开始像样 |
| L4 | +光线 | 有戏剧性 |
| L5 | +构图/色彩/细节 | 「哇」的图 |

## 四、50 分钟通用流程（两天共用）

| 时间 | 环节 | 做什么 |
|---|---|---|
| 0-8min | **开场演示** | 老师当场跑 L1→L3→L5（第一天）/ 同一主题换风格（第二天），投屏对比，制造「哇」 |
| 8-18min | **讲公式+类型** | 公式 + 8 维拆解 + 翻译步骤过一遍 + 今天的场景/风格各看范例图、拆解提示词 |
| 18-43min | **自由探索** | 学生从主题菜单选或自由发挥，反复迭代。老师巡视，记住好作品 |
| 43-50min | **展示点评** | 投屏 3-5 张学生作品，按公式点评哪里好、哪里能补 |

## 五、第一天 · 红军长征 90 周年

### ⚠️ 课前必须做的事

长征是严肃历史题材，AI 生图有**历史准确性风险**。老师课前必须：

1. **亲自跑通所有范例提示词**，检查军装 / 旗帜 / 武器的细节：
   - ✅ 正确：八角帽 + 红五星 + 灰布军装；**镰刀斧头红旗**（不是五星红旗）；汉阳造 / 老套筒步枪
   - ❌ AI 常见错误：画成解放军军衔服、画成五星红旗、画成现代武器
2. **删掉细节错的图**，只留准确的当范例，避免课堂上误导学生
3. **价值观把控**：庄重、英雄主义、缅怀先烈。色调偏历史厚重（黑白做旧 / 暖调历史油画 / 冷蓝风雪），不戏谑不娱乐化

### 范例提示词（自然段落，可直接复制到平台）

**① 爬雪山（大场景）**

```
远景镜头下，一队红军战士艰难攀爬夹金山，队伍沿对角线斜向上方延伸。战士们穿灰布军装，戴缀红五星的八角帽，肩扛汉阳造步枪，互相搀扶，领头的老兵回头拉身后的小战士。狂风暴雪呼啸，积雪没膝，远处是模糊的雪峰。写实历史纪实摄影风格，黑白做旧带轻微暖棕调。逆光，风雪中阳光被吹散成漫射光晕，人物边缘有微弱轮廓光。冷蓝白雪与暖灰人物对比，低饱和偏暗。悲壮、坚毅、英雄主义的氛围。高度细节，锐利，历史胶片颗粒质感，8K。
```

**② 过草地（大场景）**

```
远景镜头下，一队红军战士艰难跋涉在茫茫若尔盖草地，队伍在画面下方呈水平线，突出草地的辽阔与人的渺小。战士们互相搀扶，穿灰布军装，戴缀红五星的八角帽，肩扛汉阳造步枪，有人陷进沼泽被战友拉起，军装满是泥水。一望无际的草甸和黑色沼泽，阴云低垂，薄雾弥漫。写实历史纪实摄影风格，灰绿冷调。阴天漫射光，偶有光束穿透云层打在草地上。灰绿色与暖褐泥色，低饱和偏暗。悲壮、艰难、坚毅的氛围，历史厚重感。高度细节，锐利，历史胶片颗粒质感，8K。
```

**③ 三军会师（大场景）**

```
中景群像，略仰视，红军战士们欢呼拥抱，挥舞镰刀斧头红旗，有人吹冲锋号，有人相拥流泪，红旗猎猎作响，旗帜向上延伸。1936 年甘肃会宁会师，城头红旗飘扬，远处是黄土丘陵与晚霞。写实历史油画感摄影风格，暖调厚重，史诗质感。金色阳光穿透云层倾泻，英雄主义光芒。金黄暖调为主，红旗红色点缀，高饱和。胜利、激情、热血沸腾的氛围，历史时刻。高度细节，油画笔触感，史诗级，8K。
```

**④ 篝火夜宿（中场景）**

```
中景半圆构图，几位红军战士围坐篝火旁，围成弧线，篝火居中。一位老战士给年轻人讲故事，有人在补草鞋，火光映亮每个人的脸。长征途中的夜间宿营地，身后是岩石和几棵枯树，夜色深沉。写实历史摄影风格，暗调暖光，伦勃朗式光影。篝火暖橙光从下方打在脸上，背景冷蓝夜色，明暗对比强。温暖、战友情、片刻安宁的氛围。高度细节，真实火光质感，8K。

**⑤ 飞夺泸定桥（中场景）**

```
动态斜线构图，铁索形成引导线，人物从左下向右上冲锋。红军战士在铁索桥上英勇冲锋，有人匍匐前进，有人在铁索上攀爬。大渡河泸定桥，铁索悬空，桥板大半被抽走，对岸有敌军火力，下方咆哮河水，硝烟弥漫。写实历史战争摄影风格，高对比，史诗动态。侧光，硝烟中阳光形成光柱。冷蓝河水与暖橙硝烟火光对比，高对比。英勇、紧张、震撼的氛围。高度细节，动态模糊，战争质感，8K。

**⑥ 行军休息互助（中场景）**

中景双人构图，午后斜阳暖光打在两人身上，背景虚化。一位红军战士把半块干粮递给受伤的战友，两人坐在路边石头上，伤员腿上缠着绷带。山路边的休息点，背景是行军中的队伍和苍茫山色。写实历史纪实摄影风格，暖调人文。暖橙黄与灰蓝背景，柔和。战友情、温暖、艰难中的善良的氛围。高度细节，真实肤质与衣物纹理，8K。

## 六、第二天 · 多风格探索

### 教学模式

老师挑 4 个视觉语言差异明显的风格，每个风格：**展示 demo 图 → 拆解它的提示词 → 学生看 demo 学** → 最后自由发挥创作。

开场演示建议：**同一个场景（如「雨夜街道」）跑 4 种风格**，让学生直观感受「内容不变、风格一换、世界全变」。

### 范例提示词（自然段落，可直接复制）

**① 电影感（主题：雨夜归人）**

```
35mm 广角镜头，浅景深，三分法构图，人物居左。一个撑黑伞的男人背影，站在雨夜的街灯下，远处一辆老式轿车缓缓驶来。空旷的城市街道，积水倒映灯光，两侧是模糊的楼房。电影剧照风格，黑色电影质感，参考《银翼杀手》。低压钠灯暖黄光，雨丝逆光，霓虹冷光点缀，胶片颗粒，宽银幕。暖黄与深蓝青对比，高对比度。孤独、悬疑、怀旧的氛围。电影级质感，8K。
```

**② 动漫（主题：放学后的夏日）**

```
动态仰视构图，速度感斜线。一个穿校服的少女骑自行车下坡，裙摆和头发飞扬，回头灿烂微笑。小镇坡道，两侧电线杆和低矮房屋，绿荫蝉鸣，阳光斑驳。日系动漫风格，新海诚风，手绘赛璐璐。午后斜阳，逆光透发，明亮通透。饱和天蓝与暖黄绿，明亮高调。青春、清新、治愈的氛围。手绘动画质感，精致光影。
```

**③ 水彩（主题：老家的院子）**

```
平视中景，对称构图。一座老式院落，木门半开，院里有水井和葡萄架，一只橘猫趴在墙头打盹。江南老宅，青砖灰瓦，几盆花草，晾着衣物。水彩画风格，湿润晕染，笔触柔和，大量留白。清晨柔光，明亮通透。低饱和灰蓝、暖褐与柔粉点缀。宁静、怀旧、生活气息的氛围。水彩纸纹理，边缘柔化。
```

**④ 赛博朋克（主题：2077 的城市）**

```
俯视广角，夸张透视，纵深。一个穿透明雨衣的黑客少女，戴发光护目镜，站在天桥上俯瞰街道。未来亚洲城市，密集高楼，全息广告和中文霓虹，飞行器穿梭。赛博朋克风格，未来主义，参考《银翼杀手 2049》。霓虹粉紫青光，雨夜漫反射，积水倒影。粉紫青霓虹，高饱和，暗部偏蓝。迷幻、压抑、未来感的氛围。高度细节，光泽质感，8K。
```
